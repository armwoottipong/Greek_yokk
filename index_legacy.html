แจ้งเตือน: วัตถุดิบใกล้หมดสต็อก!

การเพิ่มรายการนี้จะทำให้วัตถุดิบในคลังลดลงจนต่ำกว่าเกณฑ์เตือน

รายการวัตถุดิบที่ใกล้หมด:

สต็อกยังคงมีพอสำหรับบิลนี้ แต่เหลือน้อยมาก คุณต้องการยืนยันเพิ่มรายการหรือไม่?

📖 คู่มือเชื่อมต่อ Google Sheet ใน 3 นาที

💡 สิ่งที่เตรียมไว้ให้แล้ว:

โค้ด Google Apps Script ทั้งหมดอยู่ในไฟล์ google_apps_script/Code.gs พร้อมฟังก์ชันสร้างโครงสร้างชีตอัตโนมัติ

  1. เปิด sheets.new ในเบราว์เซอร์เพื่อสร้าง Google Sheet ใหม่
  2. ไปที่เมนู ส่วนขยาย (Extensions) > Apps Script
  3. ลบโค้ดเริ่มต้นออก แล้วคัดลอกโค้ดจากไฟล์ google_apps_script/Code.gs ไปวางทั้งหมด
  4. เลือกฟังก์ชัน setupDatabase จากดรอปดาวน์ด้านบน แล้วกดปุ่ม เรียกใช้ (Run) 1 ครั้ง (ระบบจะสร้างตารางและข้อมูลตัวอย่างร้านกรีกโยเกิร์ตให้ทันที)
  5. กดปุ่มสีน้ำเงิน ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment)
  6. เลือกประเภท: เว็บแอป (Web app)
    • คำอธิบาย: Greek Yogg API
    • ดำเนินการในฐานะ: ฉัน (Me)
    • ผู้ที่มีสิทธิ์เข้าถึง: ทุกคน (Anyone) (สำคัญมาก)
  7. กด Deploy แล้วคัดลอก Web App URL นำมาวางในช่องหน้าตั้งค่าของระบบนี้!
