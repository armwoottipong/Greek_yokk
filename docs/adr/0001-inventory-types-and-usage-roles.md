# ใช้ประเภทคลังสามกลุ่มและแยกบทบาทการใช้งาน

เพื่อให้การจัดกลุ่มเข้าใจง่ายและลดหมวดซ้ำ ผู้ใช้เลือกใช้วัตถุดิบที่มีการผลิต วัตถุดิบปกติ และบรรจุภัณฑ์เป็นประเภทคลังร่วมกัน แทนหมวดชื่ออิสระที่ดูแลแยกในหลายหน้า การใช้ในการผลิต ของเสริม และเมนูเป็นบทบาทและความสัมพันธ์ที่ซ้อนกันได้ ไม่ใช่ประเภทที่จำกัดการขายหรือการเลือกส่วนผสม วันที่รับเข้า/ผลิตและวันหมดอายุเป็นข้อมูลของล็อตวัตถุดิบ ไม่ขึ้นกับหมวดหมู่

ผู้ใช้ยืนยันให้ตัดส่วนผสมตอนผลิต และตัดเฉพาะผลผลิตเมื่อขายเพื่อไม่ให้ตัดส่วนผสมซ้ำ การขายตรงใช้เมนูที่อ้างอิงรายการในคลังพร้อมปริมาณและราคา รายการในคลังไม่ขึ้นขายโดยอัตโนมัติ หน้าขายใช้การค้นหาเมนูแทนหมวดเดิม ป้ายใช้ในการผลิตเกิดทันทีที่บันทึกสูตร ส่วนป้ายใช้ในของเสริมนับเฉพาะการอ้างอิงตรง ทั้งสองป้ายอัปเดตตามสูตรที่ใช้อยู่ ข้อตกลงรายประเด็นได้รับการยืนยันแล้ว แต่ยังไม่ได้อนุมัติการแก้โค้ดหรือข้อมูล
