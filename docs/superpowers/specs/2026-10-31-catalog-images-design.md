# รูปเมนูและวัตถุดิบแบบ 1:1

## ความต้องการที่ยืนยันแล้ว

- แนบรูปเมนูและวัตถุดิบได้
- ใช้โมดูลครอปรูปร่วมกัน ให้ผู้ใช้เลือกตำแหน่งภาพเองได้
- แสดงภาพสัดส่วน 1:1
- คง layout เดิม: ตำแหน่งการ์ด ตาราง ข้อมูล ตัวกรอง ปุ่ม และฟอร์มเดิม
- ปรับเฉพาะพื้นที่ภาพตามสัดส่วน ไม่ออกแบบหน้าขายหรือหน้าสต็อกใหม่

## การใช้งานที่เสนอ

เพิ่มปุ่มเลือกรูปในฟอร์มแก้ไขเมนูและวัตถุดิบเดิม เปิดตัวครอป
กรอบสี่เหลี่ยมจัตุรัส ลากหรือใช้ตัวควบคุมตำแหน่งและซูมได้
มีตัวอย่าง ปุ่มใช้รูป และยกเลิก รองรับสัมผัสและคีย์บอร์ด
ยกเลิกแล้วรูปเดิมยังอยู่ เปลี่ยนหรือลบรูปได้ และยังใช้อีโมจิเมื่อไม่มีรูป
เก็บรูปใหม่เป็นร่างจนยืนยันบันทึก ตรวจชนิด ขนาด และข้อผิดพลาดก่อนบันทึก
ภาพไม่บิดเบี้ยวและไม่ทำให้แถวหรือการ์ดขยายตามขนาดไฟล์ต้นฉบับ

## ทางเลือกการจัดเก็บ

1. **ข้อเสนอ: Firestore แยกเอกสารรูปจากข้อมูลธุรกรรม** — บีบอัดในเครื่อง
   เป็น JPEG 512×512 ไม่เกิน 150 KiB ต่อรูปก่อนแปลงเป็น base64
   ไม่รวมรูปใน shop/catalog root หรือ operation payload ไม่เปิด billing
   ต้องทดสอบปริมาณข้อมูลและการอ่านจริง มีต้นทุนโควตา Firestore แม้อยู่ใน Spark
2. บริการฝากรูปภายนอก — รองรับรูปขนาดใหญ่ได้ แต่เพิ่มบริการและการตั้งค่าสิทธิ์

Firebase Storage ไม่เข้ากับข้อกำหนด Spark ปัจจุบัน จึงไม่เสนอให้เปิดใช้งาน
การเลือก Firestore ข้างต้นเป็นข้อเสนอของผู้พัฒนา ยังไม่ถือว่าผู้ใช้เลือกแล้ว

## ขอบเขตข้อมูลและสิทธิ์

ผูกรูปกับชนิด entity และ ID เดิม อ่านรูปตามสิทธิ์พื้นที่ของผู้ใช้
Manager/Admin แก้รูปได้ Viewer ไม่มีสิทธิ์เขียนหรือเข้าหน้าจัดการ
ห้ามบันทึก cloud เมื่อยืนยันการเชื่อมต่อ server ไม่ได้ และเก็บรูปฉบับร่างไว้
ไม่แตะสูตร ราคาขาย การตัดสต็อก ล็อต หรือเปลี่ยนสิทธิ์เดิม
ต้องเชื่อมทั้งฟอร์มเดิมและ cloud presentation มิให้รูปมีเฉพาะ local.html
ตรวจนโยบาย backup/restore สำหรับข้อมูลรูปก่อนส่งมอบ

## การตรวจรับและปล่อย

ทดสอบครอปภาพแนวนอน/แนวตั้ง ขอบเขตซูม ตำแหน่ง ผลลัพธ์ 1:1
ยกเลิก ลบรูป ไฟล์เสีย ไฟล์ใหญ่ บันทึกล้มเหลว และการแสดงผล fallback
ทดสอบสิทธิ์และ Rules ด้วย emulator ก่อนเปิดเส้นทางข้อมูลใหม่
ตรวจ UI desktop/iPad/mobile โดยเทียบ layout เดิม
รัน tests/lint/build แล้ว commit/push/deploy ตาม AGENTS.md
ตรวจ Actions และ live version.json/entry asset ก่อนรายงานว่าส่งมอบแล้ว
