# History popup UI

User requested concise, orderly, usable history popups with consistent buttons; explicitly invoked frontend-design. Scope covers the shared ActivityLogModal used by global history, stock history, per-material actions, and history entry points within receipt/adjustment stock forms.

Design: existing Thai font and shop palette retained (white #ffffff, stone #fafaf9/#292524/#78716c, positive #047857, negative #be123c). Left-aligned compact rows replace individually boxed multi-line cards. Header identifies context; one search and action selector are always visible. Date/module/material filters expand inline. A row opens complete details, retaining long notes, original titles, user, reasons, dates and recorded cost. Short Thai action names appear in the summary. Dialog height follows content, bounded at90dvh; only the list scrolls. Export/Close have visible standard buttons; destructive clear stays under labelled More and its existing confirmation.

Implementation: ActivityLogModal preserves existing store, filters, business-date grouping, CSV and clearing contracts. HistoryLogEntry is reusable presentation only. Existing ModalShell supplies nested focus/inert/Escape/restore behavior; native details summaries are included in its tab order with tabindex0. No shop data/model/storage change.
